# 스테이지 5 배경 및 UFO 아트 사양

이 문서는 스테이지 5 전투와 아레나 보스 비행 컷신에 사용할 배경 및 UFO 이미지의 권장 제작 규격을 정리한다. 수치는 현재 `stage_05.tscn`, `stage_05_cutscene.tscn`, `stage_05_cutscene.gd` 구현을 기준으로 한다.

## 화면 및 카메라 기준

- 논리 해상도: `480 x 270`
- 출력 해상도 기본값: `960 x 540`
- 스테이지 5 전장: `Rect2(-1200, -900, 2400, 1800)`
- 일반 전투 카메라 줌: `0.35`
- 컷신 최종 줌: 전체 전장을 화면에 맞추는 `_map_fit_zoom()` 사용
- 전체 화면 컷신에서 예상되는 최종 줌: 약 `0.15`

카메라 줌은 해상도와 뷰포트 비율에 따라 런타임에 다시 계산된다. 아트 크기 검토에는 `480 x 270`, 줌 `0.15`를 기준값으로 사용한다.

## 스테이지 5 전투 배경

전투 가능 영역은 `2400 x 1800`이지만, 플레이어가 경계에 있을 때 카메라 밖으로 검은 영역이 노출되지 않도록 현재 검은 바닥과 동일한 `3400 x 2800` 월드 영역을 덮어야 한다.

### 권장 원본

| 제작 방식 | 원본 크기 | 씬 배율 | 월드 크기 |
| --- | ---: | ---: | ---: |
| 픽셀 아트 권장 | `1700 x 1400` | `2.0` | `3400 x 2800` |
| 고해상도 원화 | `3400 x 2800` | `1.0` | `3400 x 2800` |

- 이미지 중심을 월드 `(0, 0)`에 배치한다.
- 중앙 `2400 x 1800`은 실제 전투 영역이다.
- 바깥쪽 약 `500` 월드 단위는 카메라 여유 영역으로 사용한다.
- 기존 스테이지 4와 비슷한 픽셀 밀도에는 `1700 x 1400`과 `2.0` 배율이 적합하다.
- 일러스트형 배경은 Linear 필터, 픽셀 아트는 Nearest 필터를 사용한다.

권장 파일명:

```text
Sprites/Background/Stage5.png
```

### 현재 적용 자산

- 파일: `Sprites/Background/Stage5.png`
- 원본 크기: `2816 x 1536`
- 씬 배율: 약 `1.82292`
- 월드 표시 크기: 약 `5133 x 2800`
- 배경 중심: 월드 `(0, -500)`
- 북쪽 절반은 바다, 남쪽 절반은 육지다.
- 전투 arena는 `Rect2(-1600, -250, 3200, 750)`로 제한해 바다 진입은 막으면서 빔의 좌우 회피 폭을 확보한다.
- 컷신도 동일한 위치와 배율을 사용해 시작 구도를 유지한다.
- 컷신에서 이미지 북쪽 끝 이후의 장거리 비행 구간은 어두운 바다색 `OceanExtension`이 UFO까지 이어진다.
- 이미지 북쪽 끝은 셰이더로 약 14% 구간을 알파 페이드해 바다색 원경과의 경계를 숨긴다.

## 컷신 배경

현재 아레나 보스는 5초 동안 화면 정북쪽으로 장거리 비행한다. UFO가 북쪽에 있어야 스테이지 5의 남북 방향 즉사 빔과 공간 구성이 일치한다.

```text
보스 시작점:   (-480, 320)
보스 도착점:   (0, -11180)
카메라 도착점: (0, -10880)
```

최종 줌에서 카메라가 볼 수 있는 영역까지 포함하면 배경에 필요한 월드 범위는 대략 다음과 같다.

```text
X: -2000 ~ 2000
Y: -12100 ~ 1400
크기: 약 4000 x 13500
중심: 약 (0, -5350)
```

월드 크기 그대로 이미지를 만들지 않고 축소 원본을 확대해 사용한다.

### 권장 원본

- 원본 크기: `1600 x 5400`
- 씬 배율: `2.5`
- 배경 중심: 월드 `(0, -5350)`
- 권장 필터: 일러스트는 Linear, 픽셀 아트는 Nearest

이 규격은 `4000 x 13500` 월드 영역을 덮는다. 주요 연출 지점을 원본 이미지 좌표로 환산하면 다음과 같다.

| 대상 | 월드 좌표 | 이미지 좌표 근사값 |
| --- | ---: | ---: |
| 플레이어 시작 구역 | `(0, 0)` | `(800, 4840)` |
| 보스 시작점 | `(-480, 320)` | `(608, 4968)` |
| UFO 도착점 | `(0, -11180)` | `(800, 368)` |

권장 구도는 이미지 하단에 지상 전장, 상단 중앙에 모선이 있는 하늘을 배치하는 세로형 구성이다. UFO는 별도 스프라이트로 표시하므로 배경의 UFO 도착점 주변은 실루엣과 발광 효과가 겹칠 수 있는 여백을 둔다.

권장 파일명:

```text
Sprites/Background/Stage5_Cutscene.png
```

세로 `5400 px` 단일 이미지의 메모리 사용이 부담되면 `1600 x 2700` 이미지 두 장 또는 반복 가능한 하늘 레이어로 분할할 수 있다. 이 경우 카메라 이동 중 이음새가 보이지 않아야 한다.

## UFO 이미지

현재 플레이스홀더는 최종 줌에서 UFO의 가로 반지름이 논리 화면 높이와 같아지도록 동적으로 확대된다.

```text
논리 화면 높이: 270 px
최종 줌: 약 0.15
UFO 가로 반지름: 약 1800 월드 단위
UFO 가로 지름: 약 3600 월드 단위
최종 화면 표시 폭: 약 540 px
최종 화면 표시 높이: 약 230 px
```

화면 폭은 `480 px`이므로 최종 구도에서는 UFO 좌우 일부가 화면 밖으로 나가는 매우 거대한 모선으로 보인다.

### 권장 원본

| 용도 | 원본 크기 | 비고 |
| --- | ---: | --- |
| 최소 규격 | `640 x 272` | 현재 플레이스홀더 기준 크기 |
| 고품질 권장 | `1280 x 544` | 코드에서 기본 크기를 절반으로 맞춰 사용 |
| 발광 여백 포함 | `1536 x 768` | 엔진광, 외곽 광원과 파편 여백 포함 |

- 투명 PNG로 제작한다.
- 피벗은 이미지 정중앙에 둔다.
- 모선 본체는 캔버스 폭의 약 80~85%를 사용한다.
- 남는 영역은 엔진광, 외곽 발광과 충돌 효과 여백으로 사용한다.
- 현재 크기 계산은 UFO의 가로 반지름을 기준으로 한다.
- 원본 크기가 변경되면 `stage_05_cutscene.gd`의 `UFO_BASE_RADIUS`를 이미지 기준 반지름에 맞춰 조정한다.

### 현재 적용 자산

- 생성 원본: `Sprites/Environment/UFO.png`, `2816 x 1536`
- 게임 적용본: `Sprites/Environment/Stage5_UFO.png`, `1536 x 1536`
- 적용본은 원본 우하단 워터마크와 합성된 체크보드 배경을 제거한 투명 PNG다.
- 현재 `UFO_BASE_RADIUS`는 적용본 너비의 절반인 `768`이다.
- 컷신 씬의 `UfoPlaceholder/Sprite`가 적용본을 사용한다.

권장 파일명:

```text
Sprites/Environment/Stage5_UFO.png
```

## 현재 코드 연결점

- 전투 씬: `scenes/stage_05.tscn`
- 컷신 씬: `scenes/stage_05_cutscene.tscn`
- 컷신 이동 및 크기 계산: `scripts/stage_05_cutscene.gd`
- 전투 배경 플레이스홀더: `stage_05.tscn`의 `BlackFloor`
- 컷신 배경 플레이스홀더: `stage_05_cutscene.tscn`의 `BlackFloor`
- UFO 플레이스홀더: `stage_05_cutscene.tscn`의 `UfoPlaceholder`

배경 자산을 적용할 때는 플레이스홀더를 즉시 삭제하기보다 실제 이미지 뒤의 검은 안전 배경으로 유지한다. UFO 자산을 적용할 때는 `UfoPlaceholder`의 위치와 동적 scale 계산을 유지하고 내부 Polygon2D 노드만 Sprite2D로 교체한다.
