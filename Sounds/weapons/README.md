# Weapon sound effects

These are mono, 48 kHz OGG derivatives prepared from the CC0 sound collection in
`/home/tuna/다운로드/Sound Effects/`. Long field recordings were trimmed to one
shot, faded, and loudness-normalized for gameplay.
